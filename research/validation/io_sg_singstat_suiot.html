  • Any bound on transmission. The result is neither an upper nor a lower bound on any behavioural response: substitution and reallocation would reduce it; income-induced consumption, which is excluded here, would increase it.
  • Any employment quantity. The SU-IOT set contains no employment row and no employment multiplier; none is derivable or emitted.
  • Any comparison with the ICIO world-table lens. Different table, different currency, different Leontief system, different baseline denominator.

Known deviations from the source, verbatim

  • Gate G1 is implemented as two sub-checks. The specification says colSums(T6 all 113 rows) == 1000; summing all n+6 rows gives 2,000 because the published Total row duplicates the components. G1 sums the n+5 component rows and G1b asserts the published Total row equals 1,000 exactly. G1b passes with a residual of exactly 0 in all four cases.
  • f_x is taken from the exports column of the symmetric table T5, not from T11 as the specification originally said. T11's export column is Theta F_d, induced domestic output rather than final demand: it differs from the published import-content base by 5.9e4 to 1.1e5 S$m, while T5's column equals it bit-exactly in all four cases. The specification was corrected in place.
  • Industry output x for the market-share matrix is taken as the row sums of P-transpose, not from T1's printed 'Total domestic output at basic prices' column. The two differ by up to 6e-4 S$m at 4 dp publication; with row sums the market-share closure test reaches 5.6e-16, with the printed column only 2.7e-7, which would fail a 1e-12 gate for a display reason. Both variants are computed and the gap is reported.
  • Targets A22 and A23 are gated at Broad Sector only. At Details the same import-content totals are genuinely different numbers (2023: Broad 519,056.5030 / 0.5332 against Details 525,814.0297 / 0.5402) because the export-weighted import multiplier is aggregation-sensitive. Domestic exports agree across levels; the import content does not.
  • Tier D import requirement is computed both ways. The published-multiplier variant follows the specification formula and passes at 1e-2 S$m; the recomputed-eta variant misses it, because a 4 dp eta multiplied by an export base of order 1e5 S$m cannot be tighter.

  • SOURCE ERROR in the agency's own 2015 publication, flagged and corrected: Table 3B-5 prints the Forward and Backward linkage column headers swapped relative to its own text and to the published data. Known deviations from the paper

  • Gate G1 is implemented as two sub-checks. The specification says colSums(T6 all 113 rows) == 1000; summing all n+6 rows gives 2,000 because the published Total row duplicates the components. G1 sums the n+5 component rows and G1b asserts the published Total row equals 1,000 exactly. G1b passes with a residual of exactly 0 in all four cases.
  • f_x is taken from the exports column of the symmetric table T5, not from T11 as the specification originally said. T11's export column is Theta F_d, induced domestic output rather than final demand: it differs from the published import-content base by 5.9e4 to 1.1e5 S$m, while T5's column equals it bit-exactly in all four cases. The specification was corrected in place.
  • Industry output x for the market-share matrix is taken as the row sums of P-transpose, not from T1's printed 'Total domestic output at basic prices' column. The two differ by up to 6e-4 S$m at 4 dp publication; with row sums the market-share closure test reaches 5.6e-16, with the printed column only 2.7e-7, which would fail a 1e-12 gate for a display reason. Both variants are computed and the gap is reported.
  • Targets A22 and A23 are gated at Broad Sector only. At Details the same import-content totals are genuinely different numbers (2023: Broad 519,056.5030 / 0.5332 against Details 525,814.0297 / 0.5402) because the export-weighted import multiplier is aggregation-sensitive. Domestic exports agree across levels; the import content does not.
  • Tier D import requirement is computed both ways. The published-multiplier variant follows the specification formula and passes at 1e-2 S$m; the recomputed-eta variant misses it, because a 4 dp eta multiplied by an export base of order 1e5 S$m cannot be tighter.
  • SOURCE ERROR in the agency's own 2015 publication, flagged and corrected: displayed equation (3A-3) prints d_ij = p_ij / x_i; the correct reading is d_ij = p_ij / x_j. Confidence VERY HIGH.
  • SOURCE ERROR in the agency's own 2015 publication, flagged and corrected: Table 3B-5 prints the Forward and Backward linkage column headers swapped relative to its own text and to the published data. The text and the published data are correct: Backward is Theta-based, Forward is Lambda-based. Proved on 6 sectors at 4 dp.
